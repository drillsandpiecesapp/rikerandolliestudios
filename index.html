Riker & Ollie's Wasteland

Rust server, live now

A PvE Rust server with 15x rates, no drops in PvE, zombies, bosses, raid bases, quests and a year-long story. The wiki covers every menu, command and perk.

To join, press F1 in Rust and type client.connect 208.52.152.43:27915, or search the server list for Riker & Ollie's Wasteland.
